# Hệ thống quản lý món ăn

## 1. Thông tin sinh viên
- Họ tên: Đinh Nhật Trường
- MSSV: 236605
- Học phần: Điện toán đám mây

## 2. Mô tả đề tài
Xây dựng hệ thống quản lý món ăn trên nền tảng đám mây,
hỗ trợ xem, tìm kiếm, thêm, cập nhật và xóa món ăn.

## 3. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Quản lý mã nguồn: Git, GitHub
- Đóng gói: Docker
- Lưu trữ image: Docker Hub
- Triển khai: Render

## 4. Cấu trúc dự án
- client/: mã nguồn frontend
- server/: mã nguồn backend API
- README.md: tài liệu dự án
- .gitignore: các tệp không đưa lên GitHub

## 5. Hướng dẫn chạy
Hướng dẫn cài đặt và chạy frontend, backend sẽ được cập nhật
sau khi hoàn thành các phần tương ứng.

## 6. Đường dẫn triển khai
- GitHub: cập nhật sau khi tạo repository
- Docker Backend: cập nhật sau khi push image
- Docker Frontend: cập nhật sau khi push image
- Render App: cập nhật sau khi triển khai
- Render API: cập nhật sau khi triển khai
